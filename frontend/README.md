# FitPlan NZ Frontend

Expo frontend for FitPlan NZ.

## Start

```bash
npm install
npm run start
```

## Environment

Copy `.env.example` to `.env` and set:

```env
EXPO_PUBLIC_BACKEND_URL=http://127.0.0.1:8010
```

Use your computer's LAN IP instead of `127.0.0.1` when testing on a physical device.
